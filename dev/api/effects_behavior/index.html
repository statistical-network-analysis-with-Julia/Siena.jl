Behavior Effects

Effects on a dependent behavior – the shape of the behavior's own objective function, network influence (contagion), degree-based effects, covariate effects, behavior interactions and thresholds.

See the Effects API Reference for the type hierarchy and the effect interface these all implement.

AverageAttHigherSimpleEffect

Siena.AverageAttHigherSimpleEffect — Type
AverageAttHigherSimpleEffect <: BehaviorEffect

Proportion of alters with strictly higher behavior: $s_i = x_{i+}^{-1} \#\{j : x_{ij} = 1, z_j > z_i\}$.

Not RSiena's avAttHigher

This is a simplified attraction-to-higher-alters effect, not RSiena's avAttHigher, whose statistic is a different function of the behavior differences. Its short name is therefore :avAttHigherSimple: the RSiena short name :avAttHigher is reserved for a numerically equivalent implementation and is deliberately not defined. Estimates from this effect are not comparable with RSiena's avAttHigher estimates.

source

AverageAttLowerSimpleEffect

Siena.AverageAttLowerSimpleEffect — Type
AverageAttLowerSimpleEffect <: BehaviorEffect

Proportion of alters with strictly lower behavior: $s_i = x_{i+}^{-1} \#\{j : x_{ij} = 1, z_j < z_i\}$.

Not RSiena's avAttLower

This is a simplified attraction-to-lower-alters effect, not RSiena's avAttLower, whose statistic is a different function of the behavior differences. Its short name is therefore :avAttLowerSimple: the RSiena short name :avAttLower is reserved for a numerically equivalent implementation and is deliberately not defined. Estimates from this effect are not comparable with RSiena's avAttLower estimates.

Behavior Effects – Behavior Interaction

BehaviorInteractionEffect

Siena.BehaviorInteractionEffect — Type
BehaviorInteractionEffect <: BehaviorEffect

Effect of one behavior on another: $s_i = \tilde z_i \tilde w_i$. RSiena: behBeh

source

BehaviorSimilarityEffect

Siena.BehaviorSimilarityEffect — Type
BehaviorSimilarityEffect <: BehaviorEffect

Similarity in another behavior: $s_i = \tilde z_i \cdot x_{i+}^{-1} \sum_j x_{ij} \text{sim}^w_{ij}$ where $\text{sim}^w$ is similarity on the other behavior. RSiena: simBeh

source

Behavior Effects – Threshold and Other

ThresholdEffect

Siena.ThresholdEffect — Type
ThresholdEffect <: BehaviorEffect

Threshold effect: $s_i = I(z_i \ge c)$.

source

PropThresholdEffect

Siena.PropThresholdEffect — Type
PropThresholdEffect <: BehaviorEffect

Proportional threshold: $s_i = \tilde z_i$ if the proportion of alters at the behavior maximum is at least the threshold, else 0.

source

BehaviorIsolateEffect

Siena.BehaviorIsolateEffect — Type
BehaviorIsolateEffect <: BehaviorEffect

Isolate effect on behavior: $s_i = \tilde z_i I(x_{i+} = x_{+i} = 0)$.

source

FeedbackEffect

Siena.FeedbackEffect — Type
FeedbackEffect <: BehaviorEffect

Product of (uncentered) similarities with all alters: $s_i = \prod_j (1 - |z_i - z_j|/r_Z)^{x_{ij}}$ (0 for isolates).

source

MainBehaviorEffect

Siena.MainBehaviorEffect — Type
MainBehaviorEffect <: BehaviorEffect

Main effect (constant tendency): $s_i = \tilde z_i$ (identical to LinearShapeEffect; kept for compatibility).
