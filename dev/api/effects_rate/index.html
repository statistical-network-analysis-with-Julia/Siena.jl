Rate Effects

Effects entering the rate function – how often an actor gets an opportunity to change, as opposed to what they do with it.

See the Effects API Reference for the type hierarchy and the effect interface these all implement.

Rate Effects – Basic

BasicRateEffect

Siena.BasicRateEffect — Type
BasicRateEffect <: RateEffect

Basic rate parameter for a period. The associated parameter is the rate $\rho_m$ itself (a positive number, as in RSiena).

Example

using Siena, NetworkCore
s50 = load_dataset(:s50)
data = siena_data()
add_dependent!(data, DependentNetwork(:friendship, s50.friendship))
add_dependent!(data, DependentBehavior(:alcohol, [s50.alcohol[:, w] for w in 1:3]))
add_covariate!(data, ConstantCovariate(:smoke1, s50.smoke[:, 1]))
state = initialize!(NetworkState(), data, 1)
rate_score(BasicRateEffect(:friendship, 1), state, data, 1)    # actor 1

Rate Effects – Other

SettingRateEffect

Siena.SettingRateEffect — Type
SettingRateEffect <: RateEffect

Rate multiplier for actors in a particular setting: score $I(v_i = \text{setting value})$, where $v_i$ is the setting covariate as given (its centring is undone, so setting_value is one of the codes in the data). A Siena.jl effect with no RSiena counterpart.

Example

using Siena, NetworkCore
s50 = load_dataset(:s50)
data = siena_data()
add_dependent!(data, DependentNetwork(:friendship, s50.friendship))
add_dependent!(data, DependentBehavior(:alcohol, [s50.alcohol[:, w] for w in 1:3]))
add_covariate!(data, ConstantCovariate(:smoke1, s50.smoke[:, 1]))
state = initialize!(NetworkState(), data, 1)
rate_score(SettingRateEffect(:friendship, :smoke1, 1, 1), state, data, 1)    # actor 1
source
