Two-Mode Effects

Effects on a two-mode (bipartite) dependent network, where senders and receivers are drawn from different node sets.

See the Effects API Reference for the type hierarchy and the effect interface these all implement.

Two-Mode Network Effects

TwoModeEffect

Siena.TwoModeEffect — Type
TwoModeEffect <: NetworkEffect

Abstract type for two-mode network effects.

source

TwoModeOutdegreeEffect

Siena.TwoModeOutdegreeEffect — Type
TwoModeOutdegreeEffect <: TwoModeEffect

Outdegree (number of events attended): $s_i = x_{i+}$.

source

TwoModeIndegreeEffect

Siena.TwoModeIndegreeEffect — Type
TwoModeIndegreeEffect <: TwoModeEffect

Event popularity: $s_i = \sum_e x_{ie} f(x_{+e})$ with $f$ identity or sqrt.

source

FourCyclesEffect

Siena.FourCyclesEffect — Type
FourCyclesEffect <: TwoModeEffect

Four-cycles: $s_i = \sum_{o \ne i} \binom{s_{io}}{2}$ where $s_{io}$ is the number of shared events of actors $i$ and $o$. Two-mode analogue of transitivity.

source

SharedEventsEffect

Siena.SharedEventsEffect — Type
SharedEventsEffect <: TwoModeEffect

Total shared events with other actors: $s_i = \sum_{o \ne i} f(s_{io})$ with $f$ identity or sqrt.

source

GWESPTwoModeEffect

Siena.GWESPTwoModeEffect — Type
GWESPTwoModeEffect <: TwoModeEffect

Geometrically weighted shared events: $s_i = \sum_{o \ne i} (1 - (1 - e^{-\alpha})^{s_{io}})$.

source

TwoModeEgoEffect

Siena.TwoModeEgoEffect — Type
TwoModeEgoEffect <: TwoModeEffect

Actor covariate effect on event attendance: $s_i = v_i x_{i+}$.

source

TwoModeEventEffect

Siena.TwoModeEventEffect — Type
TwoModeEventEffect <: TwoModeEffect

Event attribute effect: $s_i = \sum_e x_{ie} w_{ie}$ using a dyadic covariate whose rows are actors and columns are events.

source

TwoModeSameEffect

Siena.TwoModeSameEffect — Type
TwoModeSameEffect <: TwoModeEffect

Attendance with same-covariate others: $s_i = \sum_e x_{ie} \#\{o \ne i : x_{oe} = 1, |v_i - v_o| < 0.5\}$.

source

TwoModeSimilarityEffect

Siena.TwoModeSimilarityEffect — Type
TwoModeSimilarityEffect <: TwoModeEffect

Covariate similarity with co-attendees: $s_i = \sum_e x_{ie} \sum_{o \ne i} x_{oe} \, \text{sim}_{io}$.

source

TwoModeActivityEffect

Siena.TwoModeActivityEffect — Type
TwoModeActivityEffect <: TwoModeEffect

Co-attendee activity: $s_i = \sum_e x_{ie} \sum_{o \ne i} x_{oe} f(x_{o+})$.

source

TwoModePopularityAltEffect

Siena.TwoModePopularityAltEffect — Type
TwoModePopularityAltEffect <: TwoModeEffect

Actors with high outdegree attend popular events: $s_i = x_{i+} \sum_e x_{ie} (x_{+e} - 1)$.

source

TwoModeTransitiveClosureEffect

Siena.TwoModeTransitiveClosureEffect — Type
TwoModeTransitiveClosureEffect <: TwoModeEffect

Closure of four-paths: $s_i = \sum_{o \ne i} s_{io} (s_{io} - 1)$ (twice the four-cycle count).

source

TwoModeActorAssortativityEffect

Siena.TwoModeActorAssortativityEffect — Type
TwoModeActorAssortativityEffect <: TwoModeEffect

Outdegree assortativity with co-attendees: $s_i = \sum_e x_{ie} \sum_{o \ne i} x_{oe} \, x_{i+} x_{o+}$.

source

TwoModeWithinEffect

Siena.TwoModeWithinEffect — Type
TwoModeWithinEffect <: TwoModeEffect

Attendance of events within the actor's own setting: $s_i = \sum_e x_{ie} I(|v_i - w_{ie}| < 0.5)$ where $v$ is the actor setting covariate and $w$ is a dyadic covariate whose $(i, e)$ entry gives the setting of event $e$ (typically constant across rows).
