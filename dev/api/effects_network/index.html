Network Effects

Effects on a dependent network – the structural effects (basic, triadic, degree-based, isolate, GWESP), the covariate effects, the endowment/creation variants and the multiplex (cross-network) effects.

See the Effects API Reference for the type hierarchy and the effect interface these all implement.

BalanceSimpleEffect

Siena.BalanceSimpleEffect — Type
BalanceSimpleEffect <: NetworkEffect

Structural balance (similarity of outgoing tie patterns with alters), with the similarity sum normalized by $n-2$: $s_i = \frac{1}{n-2} \sum_j x_{ij} \sum_{h \ne i,j} (1 - |x_{ih} - x_{jh}|)$.

Not RSiena's balance

RSiena's balance subtracts a data-dependent centering constant $b_0$ (the mean tie-value dissimilarity over the observations) from each term instead of dividing by $n-2$, so its statistic — and hence its parameter — is on a different scale. The short name here is therefore :balanceSimple: :balance is reserved for a numerically equivalent implementation and is deliberately not defined. Estimates from this effect are not comparable with RSiena's balance estimates.

source

BetweennessEffect

Siena.BetweennessEffect — Type
BetweennessEffect <: NetworkEffect

Betweenness (brokerage): $s_i = \sum_{j \ne h} x_{hi} x_{ij} (1 - x_{hj})$. RSiena: between

NbrDist2Effect

Siena.NbrDist2Effect — Type
NbrDist2Effect <: NetworkEffect

Number of actors at distance exactly 2: $s_i = \#\{j \ne i : x_{ij} = 0, \exists h: x_{ih} x_{hj} = 1\}$. RSiena: nbrDist2

DenseTriadsEffect

Siena.DenseTriadsEffect — Type
DenseTriadsEffect <: NetworkEffect

Dense triads (tie-weighted, following RSiena): $s_i = \sum_j x_{ij} \#\{h \ne i,j : \text{triad } (i,j,h) \text{ has} \ge c \text{ arcs}\}$ with $c = 5$. RSiena: denseTriads

source

SharedInEffect <: NetworkEffect

Structural Network Effects – GWESP Family

GWESPEffect

Siena.GWESPEffect — Type
GWESPEffect <: NetworkEffect

Geometrically weighted edgewise shared partners, forward-forward (two-path closure, the GWESP analogue of transTrip): shared partners of the tie $i \to j$ are actors $h$ with $x_{ih} = x_{hj} = 1$. RSiena: gwespFF

source

GWESPBackwardEffect

Siena.GWESPBackwardEffect — Type
GWESPBackwardEffect <: NetworkEffect

GWESP backward-backward: shared partners of the tie $i \to j$ are actors $h$ with $x_{hi} = x_{jh} = 1$. RSiena: gwespBB

source

GWESPMixedEffect

Siena.GWESPMixedEffect — Type
GWESPMixedEffect <: NetworkEffect

GWESP forward-backward: shared partners of the tie $i \to j$ are actors $h$ with $x_{ih} = x_{jh} = 1$ (shared out-alters). RSiena: gwespFB

source

GWDSPEffect

Siena.GWDSPEffect — Type
GWDSPEffect <: NetworkEffect

Geometrically weighted dyadwise shared partners (two-paths, regardless of the direct tie): $s_i = \sum_{j \ne i} w(\#\{h : x_{ih} x_{hj} = 1\})$. RSiena: gwdspFF

source
