# Network Effects

Effects on a dependent **network** -- the structural effects (basic,
triadic, degree-based, isolate, GWESP), the covariate effects, the
endowment/creation variants and the multiplex (cross-network) effects.

See the [Effects API Reference](effects.md) for the type hierarchy and the
effect interface these all implement.
